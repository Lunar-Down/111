# 排序算法可视化

一个交互式的排序算法可视化工具，帮助理解经典排序算法的工作原理。

## 支持的算法

### 1. 冒泡排序 (Bubble Sort)
- **时间复杂度：** O(n²)
- **空间复杂度：** O(1)
- **原理：** 重复遍历数组，比较相邻元素并交换，直到排序完成

### 2. 快速排序 (Quick Sort)
- **时间复杂度：** O(n log n)
- **空间复杂度：** O(log n)
- **原理：** 选择基准元素，将数组分为小于和大于基准的两部分，递归排序

### 3. 选择排序 (Selection Sort)
- **时间复杂度：** O(n²)
- **空间复杂度：** O(1)
- **原理：** 每次从未排序部分选择最小元素，放到已排序部分的末尾

## 功能特性

- ✅ 实时可视化排序过程
- ✅ 彩色高亮显示比较和交换操作
- ✅ 30个随机数组元素
- ✅ 响应式设计，支持移动端

## 使用方法

1. 点击"生成随机数组"创建新的测试数据
2. 选择排序算法开始可视化
3. 观察不同颜色的柱状图表示：
   - 🟡 橙色：正在比较的元素
   - 🔴 红色：当前操作的元素
   - 🟢 绿色：已排序的元素
